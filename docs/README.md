# 🐠 AquaClass AI – Deep Learning Based Fish Species Classification

AquaClass AI is a deep learning-based web application designed to classify fish images into five different species using the MobileNetV2 architecture.

## 🚀 Project Overview

The system allows users to upload a fish image and receive its predicted species along with the prediction confidence.

## 🎯 Key Features

- Classification of 5 fish species.
- Deep learning model based on MobileNetV2.
- Image upload and prediction.
- Prediction confidence scores.
- Interactive React frontend.
- FastAPI backend integration.

## 🧠 Model Information

- Architecture: MobileNetV2
- Framework: PyTorch
- Input Size: 224 × 224 RGB
- Loss Function: CrossEntropyLoss
- Optimizer: Adam
- Learning Rate: 0.001
- Test Accuracy: **94.69%**

## 🐟 Supported Fish Species

1. Amphiprion_clarkii
2. Chaetodon_lunulatus
3. Chromis_chrysura
4. Dascyllus_reticulatus
5. Plectroglyphidodon_dickii

## 📊 Dataset Information

- Total Images: 24,971
- Training Images: 17,478
- Validation Images: 3,743
- Testing Images: 3,750

Dataset Source: [Fish4Knowledge](https://homepages.inf.ed.ac.uk/rbf/Fish4Knowledge/GROUNDTRUTH/RECOG/)
